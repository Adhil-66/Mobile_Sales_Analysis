# Mobile_Sales_Analysis
Developed an interactive Mobile Sales Analysis Dashboard using Microsoft Excel to explore sales performance, revenue trends, customer behavior, and key business metrics. Used Pivot Tables, charts, KPIs, and interactive filters to transform raw sales data into meaningful business insights.

# Mobile Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing mobile phone sales data using Microsoft Excel. It provides insights into sales performance, revenue, customer behavior, and business trends through an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Analysis
- Slicers and Filters

## Workbook Structure
- KPI – Key performance indicators
- Raw Data – Sales transaction data
- Dashboard New – Additional dashboard view
- Dashboard – Main sales dashboard

## Key Performance Indicators
- Total Revenue
- Total Units Sold
- Average Customer Ratings

## Project Objectives
- Analyze mobile sales performance.
- Identify revenue trends.
- Understand customer purchasing behavior.
- Compare sales performance across brands and cities.
- Present insights through an interactive dashboard.
